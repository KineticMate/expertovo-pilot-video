# Expertovo — pokrycie specyfikacji przez klikalne demo v2

Podstawa: `.scratch/expertovo-v2-mvp/spec.md` v1.0 i `scope.md` (Q1–Q84, Q86–Q89).

**Zakres odbioru: odwzorowanie ekranów, stanów i scenariuszy na przykładowych danych.** To nie odbiór produkcyjnej implementacji, prawdziwego AI, SMTP, bezpieczeństwa ani trwałości danych.

90/90 user stories ma przypisany ekran lub jawny ekran granicy technicznej. Nie jest to wskaźnik 100% działającego produktu. Kolumna „Odwzorowanie” określa rodzaj pokrycia. Wartości przykładowe nie są rzeczywistymi wynikami pilotażu.

Uruchomienie: otwórz `index.html`. Poprzednia wersja: `v1/index.html`, checkpoint `9d0371a00f990dc86b9220428038321b354663a8`, zachowanie kopii `1b383c4`.
